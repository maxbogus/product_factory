# Hooks — действия по событиям

Хук — это правило «когда произошло событие X, сделай Y».

## Формат

```yaml
# hooks/sources.yaml
on:
  - event: sources.collected
    when: "подтверждённых оснований < 2"
    do:
      - role: planner
        action: "добавить вопрос в план исследования"
```

## Что будет здесь

| Событие | Реакция | Приоритет |
|---|---|---|
| `sources.collected` | мало подтверждённых оснований → расширить план | P1 |
| `step.completed` | стоимость шага превысила долю бюджета → предупредить | P1 |
| `gate.opened` | вопрос человеку → сохранить и ждать | P0 |
| `budget.exhausted` | бюджет исчерпан → остановить с отчётом | P0 |

Статус: **Этап 2**. Реализация — в `src/pf/`, этот каталог хранит описания.
