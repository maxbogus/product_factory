# MCP — подключение инструментов

MCP (Model Context Protocol) — протокол подключения данных и инструментов
к агенту. Агент может работать и без него: сейчас используется локальный
корпус.

## Конфигурация

```json
{
  "mcpServers": {
    "static-parser": {
      "command": "python",
      "args": ["server.py"],
      "cwd": "tools/static-parser"
    }
  }
}
```

## Что будет здесь

| Сервер | Что даёт | Приоритет |
|---|---|---|
| `static-parser` | парсинг сайтов из разрешённых доменов | P0 |
| `document-transformer` | PDF/DOCX/XLSX/OCR | P0 |
| `parser-storage` | база знаний, полнотекст, дедуп | P1 |

Реализация — переиспользуемый код из `mcp-servers` (ваш репозиторий),
конфигурация и подключение — здесь.

Статус: **Этап 2**.
