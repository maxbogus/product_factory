# Субагенты — помощники отдельных задач

Субагент — это отдельный промпт со своей ролью, вызываемый из основного
рабочего процесса, когда задача узкая и не требует всего контекста.

## Формат

```markdown
# subagents/redteam.md
---
name: redteam
role: redteam
inputs: [variants, analysis]
outputs: [findings]
---
```

## Что будет здесь

| Субагент | Задача | Приоритет |
|---|---|---|
| `redteam` | критика одного варианта | P2 |
| `fact-check` | проверка цитат по источнику | P1 |
| `cost-audit` | разбор расхода по шагам | P2 |

Статус: **Этап 2**. Правило брифа: «число агентов само по себе не
преимущество» — субагент добавляется только если абляция покажет выигрыш
по качеству или стоимости.
