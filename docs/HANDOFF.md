   `make tasks-check` проверяет колонки, статусы, зависимости, критерии
   приёмки и доказательства закрытых задач.
2. **Передача контекста**: этот файл и `docs/sessions/`.
3. **Канон чисел** (`docs/canon.py`) + `make canon`: пересчитывает тесты,

   против канона, запрет устаревших значений, `make`-цели и пути из
   `AGENTS.md`.

   `.gitignore` — на чистом клоне `make ci` краснел (19 из 20). Теперь
