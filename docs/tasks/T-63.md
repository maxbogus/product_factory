# T-63 — артефакты прогона из одного пути

**Фаза:** 1 · **SP:** 2 · **RICE:** 9.0 · **Статус:** ✅

**Доказательство:** `tests/test_artifacts_agree.py` (критерий — `-k recheck`;
провенанс шапки — `-k journal_hash`; одна сборка — `-k one_function`)

**Критерий приёмки** — `uv run pytest tests/test_artifacts_agree.py -k recheck -q`

## Проблема

Документ демонстрации показывает **запись** прогона: статусы того кода, на
котором шла работа. На текущем коде те же ответы ролей дают другие числа
(`demo-v12`: 4 подтверждённых записи в журнале против 10 сейчас, 22 отклонено
против 8), и в документе это не было видно. Читатель принимал запись за
проверку. Плюс сборка жила в скрипте, а отчёт — в `pf.report`: две копии
правил.

## Что сделано

1. **`pf.artifacts`** — один путь сборки: `build_document` переехал из
   `scripts/build_demo_doc.py`; скрипт стал тонкой обёрткой и ре-экспортирует
   функции (тесты грузят его по пути).
2. **Провенанс в шапке** документа: журнал, первые 12 символов sha256, число
   шагов, последний шаг, правило счёта (записано / совпадает с текущим) и
   команда перепроверки. Только детерминированные от журнала поля: commit в
   документ не входит, иначе документ не мог бы совпасть с пересборкой.
3. **`pf report --recheck`** `(pf.artifacts.recheck)`: таблица «в записи
   журнала / сейчас», строка «статус изменился» и **переехавшие основания**
   («было отклонено, сейчас подтверждено») — по утверждению, если журнал
   хранит отказы с видом, иначе по ссылке. Нет `state/` — говорит
   «перепроверить нечем», а не показывает ноль.
4. **`pf.replay`** — правило повтора вынесено из скрипта замера: замер и
   перепроверка считают одним кодом (`bucket_of`, `replay_session`).
5. **Журнал не переписывается:** `recheck` только читает; тест сравнивает
   байты до и после.

## Чего задача не делает

- не пересобирает документ под текущий код автоматически: это отдельное
  действие (`make demo-doc SESSION=…`), иначе поставляемый артефакт менялся бы
  от каждой правки проверки;
- не убирает расхождение, а называет его — какое именно основание переехало и
  почему.
