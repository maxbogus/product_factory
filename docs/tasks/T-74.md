# T-74 — повтор роли называет причину: недостающие поля и обрезанный JSON

**Фаза:** 1 · **SP:** 3 · **RICE:** 3.4 · **Статус:** ✅

**Доказательство:** `tests/test_transitions.py` (критерий — `-k repair_hint`)

**Критерий приёмки** — `uv run pytest tests/test_transitions.py -k repair_hint -q`

## Проблема

Сессия 31: два падения из десяти — не на проверке оснований, а на ответе роли.
`qwen3:8b` на роли `strategy` (q2) трижды не отдал `communication` и
`verification`, и шаг упал; `analyst` и `keeper` обрывались по длине. Повтор
уже подставлял текст ошибки, но сырой pydantic-блоб модели ничего не говорит:
она повторяла тот же ответ. Отсюда три одинаковых попытки — та же ошибка.

## Что сделать

1. `Workflow._repair_hint` — разбор частых причин отдельно от сборки подсказки.
2. Недостающие поля: из текста `ValidationError` (`[type=missing]`) достать имена
   и назвать их модели («не хватает обязательных полей: `communication`,
   `verification`»).
3. Обрезанный JSON: при «обрезан»/«JSON не закрыт» просить сократить ответ.
4. Красный тест на обе ветки (фраза есть только в подсказке, не в сыром тексте
   ошибки).

## Что сделано

1. `_missing_fields(error)` — модульный helper: имена полей по блокам pydantic
   (`type=missing`, имя поля строкой выше).
2. `_repair_hint(error)` — все подсказки в одном месте; `_repair_prompt` стала
   тонкой обёрткой (сборка запроса отдельно от разбора причины).
3. Две новые ветки: недостающие поля по имени; просьба сократить обрезанный
   ответ.

**Доказательство, что тест не тавтология.** До правки оба теста красные: сырой
текст ошибки есть в запросе, а фразы подсказки («не хватает обязательных
полей», «Сократи ответ») — нет.

## Чего задача не делает

- Не меняет лимиты ответа: это `T-73`. Здесь только повтор с конкретной причиной.
- Не ловит смысловые ошибки: подсказка помогает формату ответа, а не
  правильности содержания.
