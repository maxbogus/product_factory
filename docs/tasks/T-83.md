**Критерий приёмки** — `uv run pytest tests/test_api.py -k question_form -q`

## Проблема

CLI показывает фазы, вопрос человеку и итог, но руководителю нужен один
экран: «остановить / уточнить / исправить» глазами, без терминала.

## Что сделать

1. FastAPI + SSE/WebSocket поверх `run_step`/`state` — без новой логики.
2. Экран: вопрос → лента фаз и шагов → форма ответа на вопрос агента →
   итог (стратегия, подтверждённые/отклонённые, стоимость, `needs_review`).
3. Секреты не в коде; стиль — существующий Python-стек, без лишних зависимостей.
