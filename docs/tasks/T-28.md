# T-28 — перевод в поиске и отборе: запрос RU→EN, `text_ru` для релевантности

**Фаза:** 2 · **SP:** 3 · **RICE:** 1.2 · **Статус:** ⬜

## Проблема

1. `search_web` (`src/pf/web.py:829-873`) отправляет в каналы **русский** запрос,
   а `_matches_terms` (`web.py:597-640`) считает основы русских слов. Английский
   канал не находится вовсе: arXiv по запросу «тарифы мобильных операторов» не
   вернёт ничего, даже если запрос перевести вручную.
2. `SourceBundle.is_relevant` (`sources.py:181`) и отбор строк
   (`_row_score`) работают на русских леммах и `DOMAIN_TERMS`. Английский
   материал в срез не попадает, а значит все ссылки на него отклоняются —
   «не относится к задаче».

## Что сделать

1. `src/pf/arxiv.py`: `parse_atom` (stdlib `xml.etree`, без `feedparser`),
   `search_arxiv(query, *, category=None, limit=5)`, `as_source` →
   `ground.mark_external` + `peer_review: False` в `summarize`.
   Пауза ≥ 3 с между запросами и `User-Agent` с контактом — норма arXiv.
2. `translate.expand_query(query) -> QuerySet(ru, en)`: бренды и числа
   сохраняются, проверка — тем же `numbers_of` плюс сохранность латинских
   токенов.
3. `WebSource`/`FetchedPage` получают `text_ru: str = ""`; релевантность и
   срез считаются по `text_ru or text`. **Отбор — эвристика, а не утверждение
   о факте**, поэтому перевод здесь законен.
4. `PF_TRANSLATE_SEARCH` (по умолчанию `true`) — без перевода запроса канал
   не работает вообще, это условие, а не оптимизация.
   `PF_TRANSLATE_IN_CONTEXT` (по умолчанию `false`) — английский оригинал
   **замещается** переводом того же объёма, поэтому бюджет контекста не растёт
   (условие `T-16`/`D-20`).

## Ловушки, которые надо решить явно

- arXiv **не** добавляется в `for finder in (...)` внутри `search_web`: общий
  фильтр `_matches_terms` отсечёт английские заголовки. `D-26`.
- `arxiv.org` нет в `allowed_domains` (`config.py:184`), поэтому текст берётся
  из Atom-аннотации, а не со страницы.

**Критерий приёмки** — `uv run pytest tests/test_arxiv.py -k atom -q` и
`uv run pytest tests/test_retrieval.py -k translated_relevant -q`

## Заметки

- Препринт не рецензирован — это утверждение, которое агент не имеет права
  терять: оно идёт в журнал рядом со статусом «требует проверки».
- TF-IDF-сбор терминов из `diplomMagistrate/scripts/harvest_arxiv_terms.py` не
  переносится: у проекта свой словарь (`pf.lexicon`, pymorphy3, русский).
