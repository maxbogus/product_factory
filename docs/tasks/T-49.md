# T-49 — показатель основания сверяется с показателем вывода

**Фаза:** 2 · **SP:** 3 · **RICE:** 4.2 · **Статус:** ✅

**Доказательство:** `tests/test_conclusion_grounding.py` (критерий —
`-k indicator`), `tests/test_report_conclusion.py` (`-k off_topic`)

**Критерий приёмки** — `uv run pytest tests/test_conclusion_grounding.py -k indicator -q`

## Проблема

Проверка оснований подтверждала **дословность** цитаты и не отвечала на вопрос,
**тот ли показатель** она подтверждает. Из этого вырос главный дефект серии
прогонов, названный в разборе:

- `cloud-deepseek-2` — вывод про удержание, основания про ARPU мобильной связи и
  статью об операторе;
- `cloud-deepseek-baseline-1` — вывод про удержание, основания про абонентскую
  базу (38,9 млн, +12,1 %);
- `demo-v9` — вывод «подкреплено» на строках, где стояла абонентская база.

Статус «подкреплено» при таких основаниях — ложная уверенность: цитата настоящая,
но она про другое.

## Что сделано

1. `pf.lexical.indicator_stems` — основы показателя без служебных слов
   (`GENERIC_STEMS`), одно правило для чисел плана и для этой сверки.
2. `Workflow._conclusion_topic` — показатель вывода из `expected_change` и
   `commitments[].metric`. Направление **не** входит: это текст действия, и через
   него любое основание «пересекалось» бы с выводом.
3. `Workflow._ground_indicators` — показатель основания из строки таблицы
   (`sources.indicator_of_citation`). Номер строки склеивается из `source_id` и
   поля `paragraph`: в журнале от основания остаётся только путь.
4. `pf.ground.conclusion_status(..., off_topic=True)` — потолок «подкреплено
   частично»; правило одно на рабочий процесс и отчёт.
5. Отчёт: строка «Основы не про тот показатель» с обоими показателями и
   объяснением, почему статус ниже.

## Чего задача не делает

- не судит основания без названного показателя (абзацы статей): иначе правило
  срабатывало бы на каждом выводе;
- не меняет статусы выгрузок `knowledge/raw` и переводов (`D-29`, `D-27`);
- не вводит моделей: `D-09` и вердикт `D-37` в силе.

## Замер до заморозки

Пять сохранённых журналов, сверка показателей без обращения к модели:

| Прогон | Что назвали основания | Итог |
|---|---|---|
| `cloud-deepseek-2` | ARPU мобильной связи | не совпал с удержанием, причина названа |
| `cloud-deepseek-baseline-1` | показатель не назван (абзацы JSON) | правило молчит |
| `demo-v9`, `demo-v10`, `demo-v12` | grounds нет / показатель не назван | правило молчит |

Ложных понижений — ноль, понижение статуса — только там, где показатель назван и
действительно другой.
