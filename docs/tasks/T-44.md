# T-44 — каноническое сравнение по полям

**Фаза:** 2 · **SP:** 5 · **RICE:** 2.5 · **Статус:** ⬜

## Проблема

Решение «основание подтверждено» сегодня принимается **одним порогом по
покрытию** (`pf.lexical.overlap`, `min_overlap = 0.8`). Из этого следуют оба
измеренных провала сразу:

- **ложный отказ:** «почти сорок миллионов абонентов» против строки
  `значение: 38.9` — покрытие 0,17, отказ, хотя подтверждение честное;
- **утечка:** «27,4 млн за 2016 год» против строки «накопленно с 2013 по
  сентябрь 2019» — покрытие 1,00, подтверждение, хотя период другой
  (`eval/pairs/out_of_place.jsonl`, пары `p-032`, `p-056`).

Числа, единицы и период сравниваются как проза, хотя это поля.

## Что сделать

1. `pf.canonical.CanonicalText`: язык, понятия (группы словаря), числа
   (`Quantity` из `pf.quantities`), периоды (ключ `analysis._period_key`,
   перенесённый в общий слой), точные термины, отрицание, хеш источника.
2. `pf.canonical.compare(claim, passage)` → вердикт **по полям**: какие
   понятия покрыты и каких нет, числа в базовой шкале, пересечение периодов,
   термины, добавленное отрицание. Причина отказа называет поле.
3. Подключение в `ground.verify_claim` вместо порога по покрытию; статус
   по-прежнему пишет только `grounding-gate`, `SupportStatus` не расширяется.
4. `rejected_details` и журнал шага называют поле, а не «не совпало».

## Чего задача не делает

- не добавляет моделей: `D-09` в силе;
- не ослабляет дословность: `find_quote` продолжает работать по сырому тексту
  (`D-38`);
- не поднимает статус выгрузок `knowledge/raw` и переводов (`D-29`, `D-27`).

**Критерий приёмки** — `uv run pytest tests/test_canonical.py -k fields -q`

## Заметки

- Период как ключ уже существует (`analysis._period_key`, `D-34`), но живёт
  в расчётах ряда; для утверждения его надо вызывать от текста, а не от строки.
- Порог покрытия остаётся как один из признаков, но перестаёт быть решением.
- Ожидание по замеру: ложные отказы на пересказах падают, утечка по периоду
  закрывается. Проверяется на `eval/pairs/out_of_place.jsonl` и `make replay`.
