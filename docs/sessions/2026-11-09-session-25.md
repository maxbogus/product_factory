## 1. `T-65` — противоречия источников по осям

Причина: противоречие находилось, но текст пробела был один на все случаи —
«говорят разное об одном показателе». Читатель не видел, **по чему** источники
спорят. Правило жило classmethod'ом в `Workflow` со своими копиями списков слов.

- **`src/pf/contradictions.py`** — ось считает код: `направление`
  (противоположное направление изменения) и `величина` (разные числа об одном
  показателе с тем же допуском округления). `Workflow._find_contradictions`
  делегирует туда.
- **Период — часть утверждения.** «80 % в 2019» и «70 % в 2018» — разные срезы.
  `Period.overlaps` считает соседние годы пересечением по границе, поэтому
  введена `_same_slice` — пересечение «по существу». Период с одной стороны —
  правило молчит.
- **Скил и хук, не агент.** `skills/detect-contradictions.md` подключён к
  `analyst` (`knowledge.ROLE_SKILLS`); `hooks/sources.yaml` — событие
  `facts.contradicted`, `Workflow._apply_hooks` считает противоречия. Нового
  агента нет (`D-52`).
- **Отдельный раздел отчёта** «Противоречия источников» (`##`), ось видна в
  каждой строке.
- Критерий в индексе расширен с `-k contradiction_axes` до `-k contradiction`:
  прежний ключ выбирал одну проверку из шести (`D-54`).

## 2. `T-50` — обязательство по шаблону

Причина: `Commitment` знал четыре поля; обязательство нельзя было проверить —
нет базы, метода, контрольной группы, а «пересмотреть» и «откатить» — разные
действия.

- **Схема.** `baseline`, `measurement`, `control_group`, `rollback` — пустые по
  умолчанию; унаследованный журнал читается без миграции.
- **Отчёт.** Таблица обязательства получила колонки «База», «Метод»,
  «Контрольная группа», «Откат»; счётчик «Без базы: N из M» — по образцу «Без
  владельца». Унаследованный журнал не судится: нет ключа ни у одного
  обязательства — нет счётчика.
- **Числа.** `_plan_number_texts`: `baseline` — факт (понижает статус без
  расчёта, `D-47`); `measurement` / `control_group` / `rollback` — цель.
- **Замечания.** `_check_commitment_template` даёт строки «без базы / без
  метода»; они уходят в `rejected_details` фазы решения новым видом
  `commitment-template`, без остановки (`D-55`).
- **Промпт `keeper`.** У каждого пункта пример «плохо / хорошо»; формат ответа и
  правило чисел называют базу.

## 4. Границы — названы

- Оси противоречий пока `направление` и `величина`; противоречие по субъекту или
  региону не ищется. Новая ось добавляется в `AXES` / `AXIS_TITLES` / `_axis`
  вместе с тестом.
- Поля шаблона необязательны: прогон без базы остаётся возможным, но названным.
  Замечаний за пустые `control_group` / `rollback` нет — контрольная группа есть
  не у каждой задачи.
- `make replay` противоречия не пересчитывает, а `demo/RESULT.md` пересобран из
  старого журнала: счётчика «Без базы» в нём нет, потому что поле не
  записывалось.
