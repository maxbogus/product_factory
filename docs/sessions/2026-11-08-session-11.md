## 2. `T-34` — строка расчёта проверяется по якорю из цитаты

**Дефект.** Модель копирует строку блока РАСЧЁТЫ целиком:

```
ARPU операторов связи, рублей на абонента в месяц, ВымпелКом: 302
  [project/data/telecom_arpu.csv#row0] (значение из колонки «значение», строка 1)
```

Ссылка в ответе — без якоря, путь и номер строки есть только внутри `[...]`.
Проверка искала разметку в тексте материала и отклоняла основание, хотя число
`302` в строке 0 присутствует и показатель совпадает.

**Красный прогон.** `uv run pytest tests/test_sources.py -k calc_line_quote -q`
→ **5 failed**. Два теста из семи — защитные (отказ при другом числе и
расхождение якоря): до правила они проходят тривиально, потому что
отклоняется и так всё; они держат обратную ошибку — чрезмерную мягкость.

**Правка.** `sources._calc_line_anchor` разбирает `тело [путь#rowN] (формула)`;
якорь берётся из цитаты, разметка блока текстом источника не считается,
дальше работает существующая ветка `#row`. Число сверяется со строкой с
допуском `_display_tolerance` — блок печатает `%.4g`, и `78,7913` показано
как `78,79`. Если якорь в ссылке и в цитате расходятся — отказ с причиной.

**Зелёный прогон.** 7 passed. Соседние наборы (`ground`, retrieval,
metric_semantics, conclusion_grounding) — 113 passed без регрессов.

## 3. `T-32` — журнал не принимает второй шаг с тем же номером

**Красный прогон.** `-k duplicate_ordinal` → **3 failed** (ImportError: нет
`DuplicateOrdinalError` и `_new_session_id`).

**Правка.** `Journal.append` отказывает, называя номер и файл журнала;
`pf run` берёт свободный идентификатор сессии (`s<время>`, при занятом —
`-2`, `-3`, …) вместо `s{int(time.time())}` с разрешением в секунду.

**Зелёный прогон.** 4 passed.
