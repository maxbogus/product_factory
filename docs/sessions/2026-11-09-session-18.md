## 2. `T-55` — цитата не переключает правило проверки

**Что было сломано.** Пять мест, каждое по отдельности выглядело разумно:

1. `canonicalize` брал термины после `for_comparison` (нижний регистр), и
   «мтс» перестало быть аббревиатурой — в проверке без цитаты терминов не было
   вовсе (`canonicalize('…МТС…').terms == ()`);
2. `lexical._term_present` искал `lemma('МТС')` в мешке лемм, где слов короче
   четырёх букв нет, — «МТС» не находился никогда;
3. `verify_claim` при непустой цитате уходил в **другое** правило (лексическое
   покрытие, порог 0.8), поэтому цитата ухудшала проверку верного утверждения;
4. маска чисел без сверки чисел подтверждала **любое** другое число;
5. кавычки и «ё/е» считались расхождением с источником.

**Правка.** `lexical.term_present` — одно правило терминов (сырой текст,
границы слова, гомоглифы); `mask_numbers`; `Support.kind` (семь видов:
`exact`, `number_tolerance`, `too_short`, `paraphrase`, `number_mismatch`,
`fabrication`, `language`); откат в поля — только для `too_short`,
`paraphrase`, `number_mismatch` (`QUOTE_FALLBACK_KINDS`); `normalize` снимает
кавычки и «ё», но не запятые и точки (`82,5` иначе стало бы `82 5`);
`canonicalize` берёт термины по сырому тексту, `canonical._terms_field`
делегирует в то же правило.

**Найдено существующим тестом, а не новым:** маска числа без сверки чисел
подтверждала `99,99` против `77,26` — `test_quote_with_wrong_number_is_rejected`
покраснел. Условие стало двойным: числа в допуске **и** совпадение масок.

**Пересказ — не выдумка.** Порог `PARAPHRASE_COVERAGE = 0.6` измерен: пересказ
строки таблицы — 1.00, выдуманная цитата — 0.00.

## 3. `T-56` — отказ называет настоящую причину

`SourceBundle.absence_reason` различает: ссылки нет («ссылки нет — цитировать
нечего»), ввод человека («не источник — это ввод человека, а не документ»),
источник вне среза задачи, источника нет вовсе («источник не найден среди
материалов»). `absence_kind` едет в `ClaimVerdict.kind`, `rejection_kind`
смотрит причину, а не первое знакомое слово. Подпись в контексте —
«Ввод человека (не источник, на него нельзя ссылаться)»; схему `SourceRef` не
ужесточали: иначе `roles.validate` перестал бы читать сохранённые журналы.

Побочное: `demo/RESULT.md` пришлось пересобрать (`make demo-doc
SESSION=demo-v12`) — классы отказов в документе считаются из журнала, и
`test_document_matches_its_journal` это проверяет. Журнал не переписывался.

## 4. Отклонения от плана, названные явно

1. **Идентификаторы `T-55…T-58`, а не `N1…N4`.** Гейт `make tasks-check`
   требует форму `T-01`; план называл задачи `N*`.
2. **После отката статус = статус полей, а не «ждёт проверки».** Утверждение
   проверяется тем же правилом, что и без цитаты, а вид отказа назван в
   `kind` и в пояснении. Граница записана в `D-45`: выдумка не откатывается
   никогда, поля при выдумке и так не сходятся.
3. **Кэш материалов проекта не сделан.** `SourceBundle` — `frozen=True,
   slots=True`, ленивое поле невозможно; `load_materials()` читается только для
   ссылок, которых нет ни в срезе, ни в корпусе.
4. **Тестовый модуль собирает бандл один раз на модуль.** `collect()` по
   корпусу стоит ~25 с; пять тестов не должны платить это пять раз. Каталог
   материалов при этом подменяется на каждый тест: `absence_reason` читает
   материалы по требованию.
