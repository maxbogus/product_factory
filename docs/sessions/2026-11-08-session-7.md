## Что было не так

### Английская цитата проверялась наполовину

`src/pf/ground.py:700-727` — отдельная ветка для пары «цитата на одном языке,
источник на другом»:

```python
if quote_language != source_language:
    numbers_ok, numbers_detail = numbers_match(...)
    ...
    return Support(status=NEEDS_REVIEW,
        detail="иностранный источник: дословный перевод не проверяется, сверены только числа")
```

Слова, точные термины и добавленное моделью отрицание при этом не сверяются
вовсе. То есть на английском материале работает половина механизма честности,
и по журналу нельзя понять, была ли подмена термина.

### Язык ответа не был задан

`grep` по `prompts/roles/*.md` не находил **ни одного** упоминания языка. Пока
контекст русский, это незаметно: модель отвечает по-русски «сама». На
английском материале ответ приходил по-английски — JSON формально валидный,
с русскими ключами и английскими значениями.

## Что сделано

### `T-27` — перевод как слой

`src/pf/translate.py`:

- `numbers_of` / `preserved` — числа, единицы (`%`, п.п., млн, руб.) и
  идентификаторы (`#rowN`, `T-25`, `arXiv:…`, `econ.GN`) сверяются
  **мультимножеством**; `87,5` и `87.5` — одно число; потерянное и придуманное
  число одинаково блокируют перевод;
- `TranslationStore` — кэш `knowledge/translations/<sha1[:16]>.yaml`, ключ —
  хеш **исходного** текста; числа сверяются и при чтении; непригодный перевод
  не кэшируется;
- `translate` — нарезка по абзацам и предложениям, недоступная модель даёт
  `ok=False` (деградация, не отказ), русский текст не переводится вовсе;
- `LANGUAGE_BLOCK` — требование языка, общее для всех ролей.

Правки вокруг: настройки `translations_dir` и `translate_max_chars`; третий блок в `Workflow._prompt_extras`; команда
`pf translate` (`--text`, `--refresh`, `--json`); цель `make translate`;
`.gitignore` для кэша.

### Почему перевод не стал основанием

Соблазн был прямым: разрешить русскую цитату, если она есть в переводе. Но
механизм проверки существует ровно для того, чтобы отличать пересказ от
цитаты, а перевод — это пересказ. Поэтому правило разделено (`D-27`):

- в контексте модели перевод может **замещать** оригинал (не добавляться —
  иначе окно 12288 не выдержит, `T-16`/`D-20`);
- в основании цитируется оригинал, числа сверяются с оригиналом всегда, статус
  не поднимается выше «требует проверки».
