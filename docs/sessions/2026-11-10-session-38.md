## 3. Что показал замер (честно)

- **`qwen3:8b` проходит полный цикл:** 13,7 подтверждённых оснований против
  0 у обычного чата (их некому проверить), 3 варианта. Цена — 30× токенов и
  8,8× времени.
- **2 из 3 прогонов qwen упали на `strategy`** (валидация схемы после 3
  попыток) — известная слабость 8b (сессия 31). Замер её фиксирует.
- **`deepseek-flash` во всех 3 прогонах остановился на `routing`** с
  вопросом человеку: плану не хватает данных, агент ждёт ответа. Без
  автоответа агентский прогон короче baseline; 0 оснований — это
  «остановился», а не «не нашёл».

## 4. Границы

- **Одним `make bench MODELS="qwen3:8b deepseek-flash"` нельзя:** локальная
  и облачная модели — разные провайдеры, `settings_for_model` пишет имя в
  поле текущего провайдера. Сделаны два прогона.
- **Автоответ на вопрос человеку в бенче не включён** (в матрице сессии 31
  он был). Это отдельное улучшение харнесса, а не часть `T-79`.
