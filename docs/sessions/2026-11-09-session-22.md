## 2. Разбор: модель неверна

Материал показал прямо: «услуги в России и Беларуси под торговой маркой „МТС“ …
обслужила 87,6 млн, в России — 81,9 млн, в Беларуси — 5,7 млн». То есть
81,9 + 5,7 = 87,6 — **одна компания, разные области**. Значит:

| Что сделано | Почему неверно |
|---|---|
| прочтения как непересекающиеся идентичности | иерархия — не разбиение |
| `entity-mismatch` для «МТС в России» ↔ «МТС Беларусь» | организация одна, различается область |
| страна = идентичность | «российская компания» ≠ «числа только по России» |
| `claim_narrowed` | локальное допущение вместо признака |
| «называй страну» в промптах | подгонка под одну аббревиатуру |
