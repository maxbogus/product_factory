# Материалы проекта

Здесь — данные конкретной задачи: исходные материалы, документы, таблицы,
ссылки на разрешённые источники.

Это третий слой знаний (постоянные инструкции → методики → материалы
проекта → состояние задачи). Материалы проекта — то, что относится к
конкретной задаче и не должно попасть в инструкции.

## Правила

- Только открытые источники и собственные материалы.
- Персональные данные — не хранить.
- Каждый материал сопровождается ссылкой на источник.

## Демонстрационные материалы

Сейчас используется локальный корпус Википедии (`data/wiki/`) — по сути,
материалы проекта лежат там. Отдельные материалы для демо будут добавлены
здесь после того, как появится собственная задача.

Статус: **Этап 2**.
