## Формат

Каждый файл — JSON со структурой:

```json
{
  "articles": [
    { "title": "Мегафон (компания)", "content": "…" }
  ],
  "failed_titles": [],
  "last_updated": "2026-04-17T22:16:39.462091"
}
```

Поле `failed_titles` пустое во всех файлах — загрузка прошла без потерь.

## Лицензия и атрибуция

Материал Википедии распространяется по лицензии **CC BY-SA 4.0**
(см. <https://creativecommons.org/licenses/by-sa/4.0/\>\).

- Авторы статей — см. историю версий каждой статьи в Википедии.
- Лицензия текстов Википедии распространяется на тексты статей и, при
  отдельном указании, на графику.
- Снимок получен локальным сборщиком из открытых разделов Википедии.

**Требование атрибуции:** при использовании текста статьи в демонстрации
имя автора и ссылку на источник указывать нужно явно. Агент делает это
автоматически: каждая цитата сопровождается идентификатором источника
(`<раздел>/<заголовок>`), а в журнале шагов сохраняется номер абзаца.

## Что НЕ попало в снимок

- Персональные данные, внутренние документы, закрытые данные компаний.
- Статьи, не относящиеся к 10 перечисленным разделам.
- Изображения и инфобоксы (в снимке только текст статей).

## Роль в проекте

Корпус используется как **источник фактов** в демонстрационном проекте
«Почему падает удержание у мобильного тарифа». Релевантные статьи:
`Мегафон (компания)`, `МТС (компания)`, `Конкуренция (экономика)`,
`Цена`, `Абонентская плата`, `Совершенная конкуренция`,
`Несовершенная конкуренция`, `Монополистическая конкуренция`.

Агент **не обязан** доверять корпусу целиком: каждая цитата проверяется
дословным поиском в исходном тексте статьи, а факт без подтверждённой
цитаты помечается как «нет данных» (см. `src/pf/ground.py`).
