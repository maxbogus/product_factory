# Демонстрационная задача

## Задача руководителя

> «Почему падает удержание у мобильного тарифа и что с этим делать?»

Вопрос взят из брифа Фабрики продуктов: руководителю цифрового продукта
часто приходится отвечать «почему падает удержание», «кому и как продавать
новый сервис», «что сказать аудитории, чтобы она поняла ценность».

## Ограничения

- Цену снижать нельзя — маржа.
- Данных об оттоке во внутренней телеметрии у агента нет и взять их негде.
- Источники — открытые: в демонстрации это локальный корпус Википедии.
  Веб-поиск реализован (`pf web`) и включается настройкой
  `PF_ENABLE_WEB=true`; по умолчанию выключен, чтобы прогон не зависел от
  сети.

## Что показывает демонстрация

1. **Агент ведёт работу сам** — от постановки задачи до стратегии, без
   ручных обходов.
2. **Каждое утверждение проверяется.** Цитата, которую нельзя найти в
   источнике, отбрасывается; отклонения видны в журнале с причинами.
   Вывод проверяется так же: если направление опирается на источник,
   которого нет в материалах, это сказано прямо — «вывод не подкреплён».
3. **Агент честно называет пробелы.** В корпусе нет данных об оттоке —
   агент это говорит прямо, вместо того чтобы выдумать причину.
4. **Вариантов минимум три, и они содержательно разные** — включая
   «оставить как есть» и «закрыть направление», у каждого — сильные
   возражения.
5. **Стратегия согласована**: продуктовая и коммуникационная части
   говорят об одном, и есть план проверки с нежелательными последствиями.
6. **Работа продолжается после перерыва** — состояние на диске.
7. **Видно, сколько стоило** — расход по ролям.

## Как запустить

```bash
make setup
ollama pull qwen3:8b
make doctor
make demo
```

## Как посмотреть результат

```bash
uv run pf log       # журнал шагов: основания, отклонения, стоимость
uv run pf cost      # расход по ролям
uv run pf sessions  # список сессий
cat demo/RESULT.md  # результат: замер, вывод и статус его оснований
```

Документ результата собирается из журнала: `make demo-doc SESSION=<сессия>`.

## Чего демонстрация не показывает

Честно о границах:

- **Причин оттока в корпусе нет.** Википедия даёт рыночный контекст
  (профили операторов, тарифы, конкуренция), но не внутреннюю телеметрию.
  Агент называет это пробелом — и это часть демонстрации, а не её провал.
- **Качество содержания ограничено моделью.** `qwen3:8b` — модель
  среднего размера; варианты бывают беднее, чем хотелось бы. Первое, что
  стоит попробовать, — модель побольше.
- **Веб-источники в прогоне не участвуют.** Они реализованы — `pf web`,
  `PF_ENABLE_WEB` — но по умолчанию выключены: демонстрация должна
  воспроизводиться без сети. Внешний источник, если его включить, всё равно
  остаётся «требует проверки» и подтверждённым не становится.
