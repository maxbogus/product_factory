# Skill: модельные респонденты с маркировкой синтетики

## Когда использовать

Нужно понять, как вопрос звучит для разных типов пользователя, но
реальных интервью нет. Применяется при подготовке гипотез, **не** при
выборе направления.

## Что делать

1. **Определить роли респондентов** — 3–5 разных типов, не «все
   пользователи».
2. **Сформулировать по одному вопросу на роль.** Вопрос открытый, без
   подсказки ответа.
3. **Получить ответы у модели**, задав ей роль респондента.
4. **Пометить каждое утверждение как синтетику.** Это обязательно:
   модельный ответ не доказывает спрос и не показывает распространённость
   потребности.
5. **Вынести в гипотезы, не в факты.** Ни одно утверждение респондента
   не попадает в раздел фактов: у них нет источника.

## Чего нельзя

- Выдавать синтетические ответы за реальные интервью.
- Считать количество повторов подтверждением частоты мнения.
- Использовать ответы респондентов как основание для решения — только
  как указание, что стоит спросить у настоящих людей.

## Метрики / проверка

- Каждый ответ помечен как синтетический.
- В разборе нет утверждений, взятых из ответов респондентов.
- В пробелах сказано, что реальных интервью не было.
