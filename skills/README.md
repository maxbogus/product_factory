# Skills — повторяемые процедуры

Здесь живут **скилы** агента: повторяемые процедуры, оформленные как
пошаговые инструкции с командами.

Формат скила (на примере `gigaschool_hackathon_2026/ai/skills/`):

```markdown
# Skill: <что делает>

## Когда использовать
- …

## Что делать
1. …
2. …

## Метрики / проверка
- …
```

## Что будет здесь

| Скил | Назначение | Приоритет |
|---|---|---|
| `collect-sources.md` | Сбор открытых источников с цитированием и robots | P0 |
| `analyze-data.md` | Воспроизводимые расчёты по данным демо | P2 |
| `ux-review.md` | Разбор интерфейсов по снимкам | P2 |
| `mock-respondents.md` | Модельные респонденты с маркировкой синтетики | P1 |

Статус: **Этап 2** — заполняется после замера Этапа 1 (по правилу Парето).
Скилы добавляются только если измерение покажет выигрыш.
